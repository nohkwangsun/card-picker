# card-picker — 신용카드 혜택 매니저

조사한 신용카드/체크카드 혜택 엑셀을 구조화된 JSON으로 만들고, 소비 패턴을 입력하면
카드별 예상 혜택 금액을 계산해 랭킹을 보여주는 정적 HTML 도구입니다.

## 구성

```
data/
  cards_raw.json      xlsx 원문을 기계적으로 그대로 옮긴 것 (스크립트로 자동 생성, 손대지 않음)
  benefit_tags.json   자유서술 혜택 텍스트를 계산기가 읽을 수 있게 사람이 구조화한 오버레이
  cards.json          위 둘을 카드 이름으로 병합한 최종 데이터 (index.html에도 그대로 내장됨)
scripts/
  xlsx_to_raw.py      xlsx -> data/cards_raw.json
  build.py            cards_raw.json + benefit_tags.json -> data/cards.json, index.html에 주입
index.html            혜택 계산기 앱 (데이터가 내장된 단일 파일, 더블클릭으로 바로 실행)
```

## 새 xlsx를 반영하는 방법

**방법 A — 브라우저에서 바로 (기본)**
1. `index.html`을 열고 "데이터 업데이트" 탭에서 새 xlsx 파일을 업로드합니다.
2. 카드 이름으로 기존 태깅(구조화된 혜택)과 자동으로 매칭되어 반영됩니다. 새로 등장한
   카드는 "미구조화" 상태로 추가되며, 같은 탭의 "혜택 태그 편집"에서 카테고리/할인율/한도를
   추가해줄 수 있습니다.
3. 변경사항은 이 브라우저(localStorage)에 자동 저장됩니다. "데이터 업데이트" 탭의
   내보내기 버튼으로 `cards.json`이나, 지금 상태가 그대로 내장된 새 `index.html`을
   다운로드해서 저장소 파일을 교체하면 영구 반영됩니다.

**방법 B — 스크립트로 (커밋/버전관리까지 한 번에 하고 싶을 때)**
```bash
python3 scripts/xlsx_to_raw.py 새파일.xlsx      # data/cards_raw.json 갱신
# 새로 생긴 카드가 있다면 data/benefit_tags.json에 수작업으로 항목 추가
python3 scripts/build.py                         # data/cards.json 재생성 + index.html에 주입
```

## 엑셀 원본 형식 가정

- 시트 이름에 "카드"가 들어간 시트(없으면 첫 시트) 사용
- 1행: 카드 그룹명 (병합 셀 가능, 예: 프리미엄 / 일상 / 마일리지)
- 2행: 카드 이름 (B열부터 카드 하나당 한 열)
- A열: 각 행의 속성 이름 (카드사, 연회비, 가족카드, 연간 혜택, 혜택, 멤버십, 마일리지,
  할인, 적립, 라운지, 공항, 발레파킹, Visa, 이벤트, 그외 등)

이 레이아웃만 유지되면 카드가 늘거나 줄거나 순서가 바뀌어도 그대로 반영됩니다.

## 계산 방식에 대한 주의

- 혜택은 카드마다 표현 방식이 제각각인 자유 서술형 텍스트라, `data/benefit_tags.json`에서
  카테고리(편의점/카페/해외오프라인 등)·할인율·한도·조건으로 사람이 구조화했습니다.
  아직 태깅하지 않은 카드는 계산에서 빠지고 원문 텍스트만 "카드 상세" 탭에서 볼 수 있습니다.
- 마일리지 적립형 혜택은 계산기의 "마일리지 환산가치"(기본 20원/마일)로 원화 환산해서
  다른 카드의 할인/적립 혜택과 비교합니다.
- 리터당 정액 할인(예: 주유 60원/L), 정액 캐시백(예: 6만원 이상 결제시 3만원 할인),
  구간별 한도(예: 전월실적별 한도 1만/2만원) 등은 근사치로 환산했습니다. 실제 조건은
  "카드 상세" 탭의 원문을 반드시 확인하세요.
